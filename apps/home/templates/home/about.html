What is Multiplex64?

Multiplex64 is a passion project created to serve simple and intuitive tools for internet users.

The Story

This website began at the start of 2024 as a simple test, to experiment with site hosting. Eventually, it became a small 'web tools' site, hosting various online tools. Since then, we've attracted a few people from various parts of the globe.

Values

This site is a simple passion project, nothing more for now. Updates will come slowly, but the main thing that is prioritzed is user feedback. Want to see something? Hit up the feedback form and we'll see if it can be done.

Under the Hood

Multiplex64 is built using Github and VSCode, and run on Pythonanywhere. A Python-based Django backend is used to power the current version of Multiplex64. From 2024-2026, we used Flask, but recently we have updated to Django in order to enable faster development and more robust features.
